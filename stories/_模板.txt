# ============================================================
#  新档案模板：复制这个文件、改个名字，就能开始写自己的故事。
#  （文件名以下划线开头，不会出现在游戏的档案列表里）
#
#  ── 基础写法 ──────────────────────────────────────────────
#   # 井号开头的整行是注释；指令后面也能加行尾注释（前面留个空格）：
#     @数值 学力 = 0        # 开局学力
#     > 认真学习 -> 教室 | 学力 +1    // 也可以写双斜杠
#   ⚠ 正文（剧情文字）里的 # 不会被当注释，原样显示。
#
#     @标题 我的故事                档案名
#     @开始 开场                    从哪个节点开始
#     :: 节点名                     一个节点
#     @场景 第一章 ｜ 名字           插一行小标题
#     @图片 1 小窗 / @图片 1 全屏     放图（images/档案名/1.png）
#     @图片 0                      收掉图片
#     > 选项文字 -> 目标节点         一个选项
#     -> 目标节点                   点「继续」直接跳过去
#     @结局 1 结局名 | 收尾的话       结局
#
#     > 认真学习 -> 教室 | 学力 +1      选项可以带数值变化
#     @反馈 你认真听了一节课，学力涨到了 {学力}。
#            ↑ 写在选项下面：选中后先弹一页反馈，点「确认」再进下一个节点。
#              不写 @反馈 就直接进下一个节点；这一页写什么、显露多少数值，全由你决定
#
#  ── 数值：想在界面上显示，就在节点里 @显示 ──────────────────────
#     @数值 精神值 = 60             声明一个数值（写一次就够）
#     @改变 精神值 -5               进入这个节点时生效
#     > 选项 -> 目标 | 精神值 +10     选中后加 10
#     > 选项 -> 目标 | 精神值 -5      选中后减 5
#     > 选项 -> 目标 | 精神值 = 30    选中后直接设成 30
#     > 选项 -> 目标 | 精神值 >= 50   条件不满足就不显示这个选项
#     > 选项 -> 目标 | 精神值 >= 50, 精神值 -5     条件 + 效果一起写
#     -> 目标节点 | 精神值 >= 50      条件跳转：从上往下，第一条满足的生效
#     比较符： >=  <=  >  <  ==  !=     多条用逗号或分号隔开
#
#  ── @摘要：流程图卡片上显示的那句话（建议 24 字以内）────────
#     每个节点都写一句，比如： @摘要 走廊尽头那扇门
#
#  ── 骰子 / 检定（跑团风）──────────────────────────────────
#     @数值 力量 = 3d6              初值也能掷出来（建角色属性很方便）
#     @骰 骰点 = 1d100              进这个节点时掷骰，结果写进数值
#     @骰 力气 = 3d6, 敏捷 = 3d6     一句话掷多个
#     @骰 伤害 = 2d6+1              多个骰求和再加常数
#     @改变 精神值 -1d6             效果里也能用骰子（随机伤害）
#     > 硬闯 -> 门后 | 骰点 <= 60    检定：掷骰和固定值比
#     > 硬闯 -> 门后 | 骰点 <= 力量  检定：掷骰和另一个数值比
#     正文里写 {骰点}，显示时替换成当前值
#
#  ── 循环 ──────────────────────────────────────────────────
#     节点可以指回前面的节点，数值会继承下来，用变量当计数器就能做
#     "同样一段重复几遍"的剧情（详细说明见 README）
#
#  ── 封装节点（回合制战斗那种）──────────────────────────────
#     在一个节点里写 @行动，这个节点就变成"封装节点"：
#     按钮点了在本节点内执行，不会在流程图上多出分支。
#
#     @显示 血量 条 100       侧栏显示血条（只有写了才显示）
#     @显示 背包 列表         侧栏显示数组内容
#     @显示 金币              侧栏显示一个数值
#     @行动 挥拳              一个行动按钮（点了在本节点内跑）
#     @行动 喝药 | 背包 含 药水   带条件的按钮：没药水就不显示
#     @不耗回合               写在 @行动 里：这个动作不推进回合
#     @回合                   每个回合开头自动跑（敌人反击之类）
#     -> 结局・赢了 | 血量 <= 0   封装节点的出口条件（满足就离开）
#
#     @数组 背包 = 面包, 3     数组可以混着放文字和数字
#     @加 背包 手电筒          末尾加一个
#     @删 背包 面包            删掉第一个一样的
#     @删位 背包 0             按下标删（从 0 开始）
#     @插 背包 0 火柴          插到指定下标
#     @清空 背包               清空
#     @数量 背包 -> 件数        把长度写进某个数值
#     @查找 背包 面包 -> 位置   找到写下标，找不到写 -1
#     条件里可以写：背包 含 面包      正文里可以写：{背包} / {背包[0]} / {血量}
#     语句后面能加条件：@改变 血量 -5 | 命中 >= 40
#
#     完整可跑的例子见 README「封装节点」那一节。
#
#  ── 功能按键 + 信息窗 ──────────────────────────────────────
#     @信息 物品栏            信息窗（写在节点外＝全篇通用，写在节点里＝只这个节点有）
#     身上带着：{背包}
#     钱：{钱} 块
#
#     @按键 我的背包 -> 物品栏   节点上方的小按键：打开信息窗
#     @按键 去商店 -> 商店       按键也可以直接跳到某个节点
#
#     信息窗里只放文字，打开时用当前数值展开；点一下或按 Esc 关掉。
#
#  ── 画面卡（黑屏大字 / 全屏图 / 渐显）──────────────────────
#     @画面 打字                 开一张画面卡（打字=逐字浮现；写「直接」就是一下全显示）
#     @画面 十月三日             后面每条 @画面 都是大字的一行，字号自动按字数定
#     @画面 七日轮回
#     @画面 -> 开场             放完跳到「开场」；不写 -> 就放完继续本节点
#     @画面 图片 3              改用 images/档案名/3.png 全屏铺满（图上也带底部提示）
#     @画面 图片 3 -> 走廊       图片卡放完跳转
#     只写 @画面 -> 目标 就行，不用再补一条 ->（卡片写了 -> 就一定跳走，本节点正文不再显示）
#     若箭头写在正文里，而正文一个字都没有、又只有这一条不带条件的 ->，引擎也会直接跳过去
#     一个节点一张卡（要连续两张就拆成两个节点用 -> 串起来）；
#     黑屏淡入、底部自动显示 [点击屏幕或按任意键继续]，任意键先补完打字再翻页；
#     大字里也能用 {数值} / {数组}。
#
#  写完点右下角「流程图 Tab」，就能看到自己走出来的路线图：
#  同一个节点被正常剧情走进过好几次时，卡片会叠起来（右下角 ×N），鼠标停上去微微散开，
#  点一下就把每一次进入摊成一排（第几次 / 从哪来 / 当时的数值），选一张就回到那一次的状态，
#  Esc 退回流程图。这些都自动记录，剧本里不用写任何东西；每个节点最多留最近 12 次。
# ============================================================
